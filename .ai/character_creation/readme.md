# Identidades de Personagem

`Character` representa uma identidade narrativa/operacional usada pelo usuario no VTT. Possui nome, avatar opcional e bio opcional. Pode existir livre ou vinculada a uma campanha.

Este modulo nao cria ficha ou estatisticas. Uma identidade deve continuar utilizavel mesmo sem qualquer extensao mecanica.

Tokens do VTT podem apontar para uma identidade, mas nao dependem dela. Criar e testar token generico pertence ao `campaign_scene`/`vtt`, nao a este modulo.
